# 贪吃蛇游戏 - 技术架构文档

## 1. 架构设计
```
┌─────────────────────────────────────┐
│           前端 (React)              │
├─────────────────────────────────────┤
│  组件层                              │
│  ├── App (主容器)                   │
│  ├── GameBoard (游戏画布)           │
│  ├── Snake (蛇渲染)                 │
│  ├── Food (食物渲染)                │
│  ├── ScoreBoard (分数显示)           │
│  └── GameOver (游戏结束界面)        │
├─────────────────────────────────────┤
│  逻辑层                              │
│  ├── useGameLoop (游戏循环钩子)      │
│  ├── useSnakeController (蛇控制)    │
│  └── useCollisionDetection (碰撞检测)│
├─────────────────────────────────────┤
│  状态层 (React useState/useReducer) │
│  ├── 蛇的位置和方向                  │
│  ├── 食物位置                        │
│  ├── 分数                          │
│  └── 游戏状态                        │
└─────────────────────────────────────┘
```

## 2. 技术栈
- **前端框架**: React@18
- **构建工具**: Vite
- **样式方案**: CSS Modules 或 内联样式
- **状态管理**: React Hooks (useState, useEffect, useCallback)
- **键盘事件**: 原生 addEventListener

## 3. 核心数据结构

### 3.1 游戏状态类型
```typescript
interface Position {
  x: number;  // x 坐标 (0-19)
  y: number;  // y 坐标 (0-19)
}

interface GameState {
  snake: Position[];      // 蛇身坐标数组,第一个是头
  food: Position;          // 食物位置
  direction: 'UP' | 'DOWN' | 'LEFT' | 'RIGHT';
  score: number;           // 当前分数
  gameStatus: 'playing' | 'gameover';
}
```

### 3.2 常量定义
```typescript
const GRID_SIZE = 20;      // 网格大小 20x20
const CELL_SIZE = 20;      // 每个格子 20px
const GAME_SPEED = 150;     // 移动速度 150ms
const INITIAL_SNAKE_LENGTH = 3;
```

## 4. 组件结构

### 4.1 组件列表
| 组件名称 | 职责 | props |
|---------|------|-------|
| App | 主容器,管理全局状态 | - |
| GameBoard | 游戏画布,渲染网格 | gameState |
| Snake | 渲染蛇身 | positions |
| Food | 渲染食物 | position |
| ScoreBoard | 显示分数 | score |
| GameOver | 游戏结束界面 | score, onRestart |

### 4.2 游戏循环流程
1. 初始化游戏状态 (蛇身、食物、分数)
2. 启动定时器 (setInterval, 150ms)
3. 每帧执行:
   - 根据方向更新蛇头位置
   - 检测碰撞 (墙壁、自己的身体)
   - 检测是否吃到食物
   - 更新分数和蛇身长度
   - 重新渲染

## 5. 键盘控制

### 5.1 方向映射
| 按键 | 方向 |
|------|------|
| ArrowUp / W | 上 |
| ArrowDown / S | 下 |
| ArrowLeft / A | 左 |
| ArrowRight / D | 右 |

### 5.2 控制约束
- 不能直接掉头 (例如:当前向上,不能立即向下)
- 方向变更在下一次移动时生效

## 6. 碰撞检测逻辑

### 6.1 墙壁碰撞
```typescript
if (newHead.x < 0 || newHead.x >= GRID_SIZE ||
    newHead.y < 0 || newHead.y >= GRID_SIZE) {
  // 游戏结束
}
```

### 6.2 自身碰撞
```typescript
if (snake.some(segment => 
    segment.x === newHead.x && segment.y === newHead.y)) {
  // 游戏结束
}
```

## 7. 食物生成
- 随机生成位置
- 确保不在蛇身上
- 吃到食物后:
  - 蛇身长度 +1
  - 分数 +10
  - 生成新的食物位置

## 8. 游戏状态管理
```
状态流转:
START → PLAYING → GAME_OVER
  ↑                   ↓
  └──── RESTART ──────┘
```

## 9. 性能优化
- 使用 useCallback 缓存函数
- 避免不必要的重新渲染
- 使用 CSS transform 进行动画
